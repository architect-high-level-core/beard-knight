# scripts/

Helper scripts (excluded from the Jekyll build). Run from the repo root.

## Daily routine – after adding a new ENGLISH post

```sh
# 1) SEO description (only if the post has no description: yet)
python3 scripts/seo_descriptions.py _posts/YYYY-MM-DD-slug.md

# 2) Related posts + image dimensions
python3 scripts/build_seo_data.py

# 3) Read-aloud MP3 with chapters (EN only; needs /workspace/.venv-tts with edge-tts)
/workspace/.venv-tts/bin/python scripts/make_audio.py --chapters _posts/YYYY-MM-DD-slug.md

# 4) Commit and push (GitHub Pages builds from main)
git add _posts assets/audio _data && git commit -m "Add post + audio + SEO data" && git push
```

One-liner for a brand-new EN post that already has a hand-written `description:`:

```sh
python3 scripts/build_seo_data.py \
  && /workspace/.venv-tts/bin/python scripts/make_audio.py --chapters _posts/YYYY-MM-DD-slug.md \
  && git add _posts assets/audio _data && git commit -m "Add EN post + audio" && git push
```

Do **not** run `make_audio.py` on `tr/_posts/` – audio is English-only.

## SEO / GEO data

```sh
pip install pyyaml pillow              # once
python3 scripts/seo_descriptions.py    # adds description: to EN posts that lack one
python3 scripts/build_seo_data.py      # rewrites _data/related.yml and _data/images.yml
```

* `seo_descriptions.py` – takes the post's own `excerpt` or first prose paragraph
  (markdown stripped) and cuts it to ~158 characters. Never overwrites an existing
  `description`. Prefer writing a 1–2 sentence `description:` yourself.
* `build_seo_data.py` – related posts (shared tags/title words) and image sizes.
  Only scans `_posts/` (English).

**Nothing breaks if you skip these** for a new post: meta falls back to the excerpt,
related falls back to the most recent EN posts, images without a size entry render
without width/height.

## Other

* `make_audio.py` – read-aloud audio generation with chapters (free edge-tts, local, English posts only).
  **Daily command for every new EN post** (always with `--chapters`):

  ```sh
  /workspace/.venv-tts/bin/python scripts/make_audio.py --chapters _posts/<date>-<slug>.md
  ```

  It speaks the post section by section (one per `##` heading), writes `audio:`, `audio_voice`,
  `audio_duration` and `audio_chapters:` (`{t: seconds, title: "..."}`) to the front matter and the MP3 to
  `assets/audio/`. Sections under 60 s are merged into the previous chapter and at most 10 chapters are
  kept. Add `--force` to regenerate an existing MP3 and keep the existing `audio_voice`. Run one TTS job
  at a time. Never run this on `tr/_posts/` – audio and chapters are English-only.
  Chapters feed the post player (ticks + collapsible list) and the English homepage now-playing bar.
* `test/search.test.js` – whole-word search tests (`node scripts/test/search.test.js`).

## Generated by Jekyll (no script)

`/sitemap.xml` (jekyll-sitemap), `/feed.xml` (jekyll-feed), `/robots.txt`,
`/llms.txt`, meta/Open Graph (`_includes/seo.html`) and JSON-LD
(`_includes/schema.html`). Verification codes go in `_config.yml`
(`google_site_verification:` / `bing_site_verification:`).
